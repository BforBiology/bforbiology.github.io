SETUP GUIDE

Upgrade your B for Biology website

This is a replacement set of files for the existing GitHub Pages repository, not a separate website. Hosting remains free.

Before you upload

Download a backup of the existing repository from GitHub → Code → Download ZIP. Keep your current data/content.json if you published newer lessons.

Recommended deployment

  1. Install free GitHub Desktop, sign into your GitHub account, and clone BforBiology/bforbiology.github.io.
  2. Extract the upgrade ZIP and copy all contents into the cloned repository folder. Allow replacement of existing site files. If your online content is newer than this package, preserve the online data/content.json instead of replacing it.
  3. In GitHub Desktop review the changed files, select Commit to main, then Push origin.
  4. Check GitHub Pages is set to publish from main and /(root).
  5. Open your site, click a lesson to check its own URL, and view the sitemap.

Publishing new lessons

  1. Open Creator Studio and connect using your fine-grained repository-limited GitHub token.
  2. Add a note, video, image or quiz and click Save resource locally.
  3. Click Publish all to GitHub. Keep the tab open. The upgraded publisher writes the resource library, individual HTML lesson pages and sitemap.
  4. Verify the new page is visible on the public website.

Search Console

Submit sitemap.xml in Google Search Console → Sitemaps. Indexing is never guaranteed.

Security and monetization

Do not upload tokens or student data to this public repository. The dashboard is a static public page requiring GitHub permission to publish; it is not a true private admin server. Update the Privacy Policy and commercial disclosures before adding ads, analytics or affiliate links. Check GitHub Pages and ad-network terms first.
