FREE WEBSITE SETUP

Publish & manage your website

No hosting purchase, domain purchase or coding required.

Step 1 — Publish on GitHub Pages

  1. Create a free account at github.com.
  2. Create a new public repository named bforbiology.
  3. Use Add file → Upload files to upload all files and folders inside this website folder, including index.html and the assets and data directories.
  4. Click Commit changes.
  5. Under Settings → Pages choose Deploy from a branch → main → /(root), then Save.
  6. Your free address will be https://YOUR-USERNAME.github.io/bforbiology/.

Need more detail? Read the official GitHub instructions.

Step 2 — Set up your private publishing permission

  1. In GitHub visit Profile Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate a token with access only to the bforbiology repository.
  3. Under repository permissions select Contents: Read and write.
  4. Copy the token, open Creator Studio, enter username, repo, branch and token, and select Load from GitHub.
  5. Never send this token to anyone and never put it in your public files. Disconnect after each editing session.

Step 3 — Upload your content

Notes: Choose Note, fill lesson text, save, then publish. You can also upload a PDF and paste the resulting file path in the PDF URL field.

Videos: Upload videos to YouTube, paste the watch URL in a new Video resource, then publish. Large videos should not be stored on GitHub.

Images: Upload your own diagrams as PNG/JPG/WEBP/SVG and paste the resulting path in Image URL and/or Cover URL.

Quizzes: Choose Quiz and add questions in JSON format. Sample: [{"question":"What is the powerhouse of the cell?","options":["Ribosome","Mitochondrion"],"answer":1}].

After editing, click Publish all to GitHub. Until then, changes remain only in a local browser draft.

Important to know

GitHub Pages serves public static files. This does not include student accounts, a private database, payments, server-side subscriptions or automatic monetization. Uploads in this dashboard are limited to 8 MB each; use YouTube for videos. The website is only live after you create and deploy it in your GitHub account.
