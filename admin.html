Getting started?

Read the step-by-step setup guide. You can edit content offline, but GitHub connection and file uploads need an internet connection and a website served through HTTPS (GitHub Pages).

Security: Anyone can open this admin page, but nobody can publish without permission to your repository and a valid token. For additional privacy, remove admin.html from your published site and run it locally with a simple local web server.
